# 数据说明

## 来源

B 站网页端逐条人工录入（非官方接口）。录入字段包括：账号名、开号/首发时间、视频 bvid、发布时间、
播放量、点赞、投币、收藏、评论、时长。

**录入存在缺漏**：粉丝数少于一定量级的账号、删除的视频、以及部分早期视频可能未被收录，
因此总量偏低。所有结论以相对比较为准，不宣称代表平台全貌。

## 剔除

以下 3 个账号虽使用 AI 工具，但内容不属于「AI 运营账号」这一题材，已剔除：

- 暮之鸣
- 一支小馋猫
- lmlmlmlmzh

剔除后：**839 个账号 / 10,664 条视频 / 3,728 万播放**。

## 字段

### video.csv

| 字段 | 说明 |
|---|---|
| bvid | B 站视频 ID（去重键） |
| account_id | 账号 ID |
| account_name | 账号名 |
| pub_time | 发布时间（ISO 8601，+08:00） |
| view | 播放量（截至 11-11 的快照） |
| like / coin / favorite / comment | 互动数 |
| duration | 时长（秒） |

### account.csv

| 字段 | 说明 |
|---|---|
| account_id / account_name | 账号 |
| first_pub_time | 首个视频发布时间（用作「开号时间」） |
| last_pub_time | 最后一个视频发布时间 |
| video_count | 视频数 |
| total_view | 累计播放 |

### account_day.csv

账号 × 日期 的发布量与播放量明细，用于队列分析。

## 口径与已知偏差

1. **播放量是快照值**：截至 2026-11-11，越晚发布的视频累积时间越短，
   因此「按发布日统计播放」会天然偏低，本片只在明确注明的地方使用该口径。
2. **停更** = 最后一次发布距 11-11 超过 7 天。
3. **队列分析**按 5 天一批分组，取组内每条视频播放的中位数。
4. **Gini 系数**基于账号累计播放计算，剔除上述 3 个账号后为 0.905。
5. 直播、动态、专栏不在统计范围内。
